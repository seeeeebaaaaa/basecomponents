# AIInstructions

Modular instructions for coding agents, copied into projects with `grab AIInstructions`.
Edit files here in basecomponents, not in a project. Push changes back with `give AIInstructions`.

Structure:

- `index.md` entry point, imported from the project CLAUDE.md
- `setup/` ordered steps for setting up a new project
- `reference/` lookup docs (layout widths, package APIs)
- `conventions/` code and styling rules
