# AI instructions index

Read this file first. Only open the module you need for the current task.

## Setup

- `setup/01-mfsetup.md` the `mfsetup` command. Setup is done by the command, not by the agent.

## Modules for tasks

- `setup/02-mf-context.md` reading values from the context, context rules
- `setup/03-part-splitter.md` adding or changing parts driven by the CMS property `part`
- `setup/04-translations.md` adding or changing translated strings

## Reference (read when building layouts, using package APIs or tracking)

- `reference/layout-grid.md` width containers from `@ta-interaktiv/react-disco-grid`
- `reference/tracking.md` GA4 event names and values, sent via trackEvent

## Conventions (always apply)

- `conventions/code.md` components, styling, comments, Shadow DOM
- `conventions/assets.md` image naming for light/dark and desktop/mobile, `url()` for file paths

## Tasks (read only when the user asks for it)

- `tasks/tracking-suggestions.md` suggest tracking events, usually shortly before a project is finished
